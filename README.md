A single original one-line roast of a fridge for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) on make.fun. The program is `main.ts` (Node 22 standard library only): it holds the roast as one string, validates it is a single non-blank line of 1–200 characters and under 800 UTF-8 bytes, then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the output directory if needed.
